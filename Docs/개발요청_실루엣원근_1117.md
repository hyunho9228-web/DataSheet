# 개발 요청: 앞 가림 실루엣 원근 (11/17)

작성: 기획 김현호 · 출처: 개발요청_통합_1116 6장 (아직 클라이언트 미적용)

## 지금
- 실루엣은 기획이 도화골·협곡·가마터 맵 프리팹에 직접 넣습니다.
- 지금 원근 코드는 Background 아래 "Sky"·"Mountains"만 찾기 때문에, 실루엣은 **땅과 같이 움직입니다.** 이대로 두면 개발 작업은 없습니다.

## 요청 (선택: 원근을 원할 때만)
땅보다 빨리 지나가는 앞 가림 원근을 위해:

| 항목 | 값 |
|---|---|
| 원근 대상 | `Background/Silhouette` 연결 |
| 가로 속도 | 13000 (땅의 1.3배) |
| 세로 속도 | 10000 (땅과 같이. 세로도 빠르면 아래 보기 때 발을 가림) |
| 그리는 순서 | 캐릭터·몬스터·재화보다 **앞**, HUD·타격 이펙트·데미지 숫자보다 **뒤** |

## 연결 뒤 기획 할 일
- StageLayer에 SILHOUETTE 행 **9024~9026** (도화골·협곡·가마터) 추가.
- 실루엣 그림은 아트 담당이 다시 그리는 중(학원 PC 클라우드\실루엣_아트전달_1116).
