# 개발 요청: NPC 이름표·말걸기 안내 겹침 (수정 대기)

- 날짜: 2026-11-16 / 요청: 김현호(기획)
- 상태: **수정 대기.** 지스타 빌드가 이미 진행 중이라 이번 빌드에는 넣지 않고, 빌드 뒤에 반영합니다.
- 발견 위치: 도화골(8001) 피난민 NPC, 플레이 중 화면
- 그림: `NPC이름표_말걸기_겹침_1116.png`

![겹침 화면](NPC이름표_말걸기_겹침_1116.png)

## 1. 문제

| # | 문제 | 지금 화면 |
|---|---|---|
| 1 | 이름표 "피난민"이 머리 바로 위가 아니라 한참 위에 떠 있음 | 머리와 이름 사이가 캐릭터 키만큼 벌어져 누구 이름인지 알기 어려움 |
| 2 | 이름표 글자가 너무 작음 | 배경(불·나무)에 묻혀 거의 안 읽힘 |
| 3 | "F 말걸기" 안내 상자가 피난민 몸(머리·상체)을 가림 | 말을 걸 대상이 안 보임 |

## 2. 지금 값이 정해지는 곳 (학원 PC GitFork 사본 기준, 읽기만 함)

| 항목 | 위치 | 종류 |
|---|---|---|
| 이름표 높이 | `Adapters/Interaction/NpcTalk.cs` 33행 `localPosition = Vector3.up * 2.5f` | **코드 고정값.** 로컬 좌표라 NPC 프리팹의 크기(Scale)만큼 곱해져 실제로는 더 높이 뜨는 것으로 보임 |
| 이름표 글자 크기 | `NpcTalk.Configure(..., nameTemplate)`로 넘겨받는 TextMesh 틀 | 그 틀 프리팹의 Character Size·Font Size |
| 말걸기 안내 높이 | `PlayerInteractor.cs` 인스펙터 "대상 위 표시 높이 (타일)" `_promptHeight` = 1.5 + 표시 글자 프리팹의 위치 y | 인스펙터·프리팹 값. 단, **서낭당·문·명부 등 모든 상호작용 대상이 같이 씀** |
| 말걸기 기준점 | 대상의 `Position`(발밑 기준) | 코드 |

정리하면 이름표 높이는 코드라 개발이 고쳐야 하고, 말걸기 높이는 인스펙터 값이지만 하나로 다 같이 움직여서 NPC만 따로 올릴 수 없습니다.

## 3. 요청 (제안값)

**① 이름표를 머리 바로 위로**
- NPC 그림(SpriteRenderer)의 위 끝에서 **0.3타일** 위에 이름표를 둡니다. 고정 2.5 대신 그림 크기를 기준으로 계산하면 NPC 크기가 달라져도 맞습니다.
- 어려우면 NpcTalk에 "이름표 높이(타일, 월드 기준)" 인스펙터 칸을 열어 주시면 기획이 NPC마다 맞추겠습니다.

**② 이름표 글자 키우기**
- 지금 크기의 **2배**. 배경에 묻히지 않게 글자 테두리(외곽선) 또는 그림자를 넣어 주세요.
- 기준: 화면 크기 5(카메라)에서 "F 말걸기" 글자 높이와 비슷하거나 조금 작게.

**③ 말걸기 안내가 NPC를 가리지 않게**
- 권장안: 말걸기 안내를 **이름표 바로 위**에 띄웁니다(아래에서부터 NPC → 이름 → F 말걸기 순서). 이름과 대상이 모두 보입니다.
- 구현 제안: 상호작용 대상별로 안내 높이를 정할 수 있게(예: NPC는 그림 위 끝 기준) 하고, 공통 `_promptHeight`는 서낭당·문·명부에 그대로 둡니다. 공통값만 올리면 다른 대상의 안내도 같이 떠 버립니다.
- 다른 안(택1 가능): 말걸기가 떠 있는 동안 이름표를 숨기고 그 자리에 "F 말걸기"를 띄움. 다만 이 경우 가까이 가면 이름이 사라집니다.

## 4. 확인 방법
- 도화골 피난민 앞에 서서 이름표가 머리 바로 위에 붙어 있는지, 글자가 배경 위에서 읽히는지, "F 말걸기"가 몸을 가리지 않는지 봅니다.
- 같은 빌드에서 서낭당·문·명부 안내 높이가 바뀌지 않았는지도 봅니다.
