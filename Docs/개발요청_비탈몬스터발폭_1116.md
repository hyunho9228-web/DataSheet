# 개발 요청: 잡몹이 비탈에서 떠 보임 (버그, 11/16)

요청: 잡몹이 비탈 위에 있을 때 그림을 비탈 그림에 붙여 주세요. 아래 **방법 A(그림만 내리기)**가 수정이 가장 작습니다.

- 증상: 산길 x31~36 V자 비탈(기울기 0.5)에서 허수귀가 비탈보다 약 0.5칸 떠서 걷고 섬. 플레이어는 거의 붙어 있음.
- 원인: 잡몹이 비탈을 따라 높이를 잴 때 **몸 판정 사각형 폭 전체**(허수귀 1.875칸, 지게귀 2칸, 옹귀 1.875칸)로 바닥을 잽니다. 넓은 상자를 비탈에 놓으면 위쪽 모서리가 먼저 닿아서, 그림이 있는 가운데는 (폭 절반 × 기울기)만큼 뜹니다. 허수귀는 0.94 × 0.5 = 약 0.47칸입니다. 플레이어는 폭 0.6칸이라 0.15칸만 뜹니다.
- 몬스터는 떨어지지 않아서, 서 있는 동안에는 뜬 높이가 그대로 남습니다.

## 방법 A (추천, 수정 작음): 비탈 위에서만 그림을 내려 그리기

| 항목 | 요청 |
|---|---|
| 언제 | 잡몹이 비탈(GroundSlope) 위에 서 있거나 걸을 때 |
| 무엇을 | 그림만, 몸 가운데 바로 아래 땅 높이와 지금 발 높이의 차이만큼 아래로 내려 그림. 곧은 비탈에서는 (몸 폭 절반 × 기울기)로 허수귀·옹귀 약 0.47칸, 지게귀 0.5칸. V자 바닥처럼 양쪽 비탈에 걸친 곳은 그보다 작음 |
| 그대로 둘 것 | 이동·바닥 판정·맞는 판정·공격 판정·어그로 높이 비교는 지금 그대로 |
| 평지 | 내리는 값 0(지금과 같음) |
| 확인 | 산길 GroundSlope 1~9 비탈에서 잡몹 발이 비탈 그림에 닿는지, 비탈과 평지 사이를 지날 때 그림이 튀지 않는지 |

## 방법 B: 바닥 재는 발 폭을 좁게 (처음 요청안)

| 항목 | 요청 |
|---|---|
| 바닥 재는 폭 | 잡몹도 좁은 발 폭(플레이어처럼 0.6칸 안팎)으로 바닥·비탈 높이를 잼 |
| 그대로 둘 것 | 맞는 판정·공격 판정·돌진 접촉 폭은 지금 크기 유지 |
| 벽·낭떠러지 | 벽에 막히는 것과 걷는 구간 끝은 지금처럼 몸 폭 기준이어도 됨 |

## 맵·프리팹으로 안 되는 이유

- 비탈 Ground 콜라이더만 내리면: 플레이어도 같이 묻히고, 비탈과 평지 사이에 턱이 생겨 걷다가 멈춤(11/16 확인).
- 프리팹 Body 폭을 줄이는 방법도 있지만 맞는 판정까지 좁아져서 쓰지 않았습니다.
- 참고: 11/16 학원 PC 프리팹에서 플레이어·잡몹 그림과 몸 판정을 0.2칸 내렸습니다(Body y, 잡몹은 PreviewSprite도). 작업 브랜치에 있고 아직 커밋 전입니다. 이 장과는 별개입니다.
