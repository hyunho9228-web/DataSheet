# 빌드 피드백 개발 전달

2026-11-13 · 작성 김현호(기획) · 대상 빌드: 11/13에 올라온 빌드

11/13 빌드를 플레이하며 나온 36개 가운데 개발에서 작업할 22개만 모았습니다. 번호는 원래 피드백 번호입니다. 빠진 번호는 기획·아트에서 처리하는 항목입니다.
