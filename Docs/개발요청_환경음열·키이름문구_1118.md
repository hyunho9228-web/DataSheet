# 개발 요청: 맵 환경음 데이터 연결, 키 이름 문구 표시 (11/18)

DataSheet main `e49a1c6`에 데이터를 올렸습니다. 두 건 모두 데이터는 준비됐고, 게임에서 읽도록 연결만 하면 됩니다. 지금 게임 동작은 바뀌지 않았습니다.

## 1. 맵 환경음을 Stage 표에서 읽기

### 지금
맵마다 어떤 환경음을 틀지가 코드에 고정돼 있습니다. 그래서 새 맵(갈림길 뒤 산사·폐광 5개)을 넣거나 맵 환경음을 바꿀 때마다 코드를 고쳐야 합니다.

### 추가한 데이터
`tables/Stage.xlsx` Stage 탭 맨 오른쪽(Note 뒤)에 **AmbienceSoundID** 열을 추가했습니다.

| 열 | 형식 | 뜻 |
|---|---|---|
| AmbienceSoundID | 정수, 빈칸 허용, Sound 표 ID 참조 | 그 맵에서 배경음과 겹쳐 반복할 방 환경음. 비우면 환경음 없음 |

값은 지금 코드에 있는 짝을 그대로 옮겼습니다. 바뀌는 소리는 없습니다.

| Stage | 맵 | AmbienceSoundID | Sound 비고 |
|---|---|---|---|
| 8001 | 도화골 | 3046 | 1번방 환경음 |
| 8005 | 장부방 | 3047 | 2번방 환경음 |
| 8002 | 산길 | 3048 | 3번방 환경음 |
| 8006 | 옹기 가마터 길 | 3048 | 3번방 환경음 |
| 8007 | 갈림길 | 3048 | 3번방 환경음 |
| 8003 | 협곡 | 3049 | 4번방 환경음 |
| 8004 | 보스방 | 3050 | 5번방 환경음 |

Sound 3046~3050은 모두 Loop=Y(반복)입니다. DeployData가 없는 Sound ID를 넣으면 배포 전에 막습니다.

### 요청
1. 클라 Stage 정의에 AmbienceSoundID를 추가해 주세요(스키마 변경이라 정의 클래스는 자동 갱신되지 않습니다).
2. 맵에 들어갈 때 이 열의 Sound ID로 환경음을 틀어 주세요. 지금 코드에 고정된 맵별 환경음 짝은 이 데이터로 대체해 주세요.
3. 빈칸이면 환경음을 끄고, 앞 맵과 같은 ID면 끊지 않고 이어서 재생해 주세요(지금 동작과 같음).

### 확인
도화골 → 산길 → 가마터 → 갈림길 → 협곡 → 보스방, 도화골 ↔ 장부방을 오가며 지금과 같은 환경음이 나오는지, 산길·가마터·갈림길 사이에서 소리가 끊기지 않는지 확인.

### 참고(이번 요청 아님)
- Stage의 BGM_Normal·BGM_Battle은 지금 게임이 읽지 않는 것으로 보입니다. 배경음도 데이터로 바꿀지는 지스타 뒤에 따로 정하겠습니다.
- 타이틀 환경음(Sound 3079)은 Stage 행이 없어 이 열과 상관없습니다. 타이틀에서 3079가 나오도록 따로 연결해 주세요.

## 2. 키 이름을 Language 문구로 표시

### 지금
시작 안내·조작 안내·조작 선택 화면에서 키 이름이 한국어 화면에서도 영어로 나옵니다(예: "Left Shift 패링", "SPACE").

### 추가한 데이터
`tables/Language.xlsx`

| Language ID | KO | EN | UI_Lang ID | Key |
|---|---|---|---|---|
| 30389 | 왼쪽 Shift | Left Shift | 51318 | Controls.Key.LeftShift |
| 30390 | 오른쪽 Shift | Right Shift | 51319 | Controls.Key.RightShift |
| 30391 | 스페이스 | Space | 51320 | Controls.Key.Space |

방향키는 이미 있는 30242 "방향키 / Arrow Keys"(UI_Lang 51315 Controls.Key.ArrowKeys)를 써 주세요.

### 요청
1. 키 이름을 화면에 보일 때 위 세 키는 이 문구로 바꿔 주세요. 언어를 바꾸면 같이 바뀌어야 합니다.
   - A안 패링: 왼쪽 Shift / Left Shift
   - B안 패링: 오른쪽 Shift / Right Shift
   - A안 구르기: 스페이스 / Space
2. 글자 키(C·X·Z·Q·K·J·L·U·I·F 등)는 지금처럼 글자 그대로 둡니다.
3. 적용할 곳: 도화골 시작 안내(패링 줄), 일시정지 조작 안내, 조작 선택 화면.

### 확인
KO/EN × A안/B안 네 경우로 도화골 시작 안내의 패링 줄과 조작 선택 화면을 보고 키 이름이 언어에 맞게 나오는지 확인.

## 같이 알려 드릴 것
- 시작 안내의 이동 줄(UI_Lang 52201, Language 30368)은 일부러 뺀 것이 맞습니다. 되살리지 않습니다.
- 조작 선택 화면 키 줄에 패링 키가 빠져 있습니다. 넣을지는 개발 판단에 맡깁니다.
