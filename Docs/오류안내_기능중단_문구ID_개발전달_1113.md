# 오류 안내·기능 중단 문구 ID 개발 전달 (11/13)

작성: 기획 김현호 · 상태: **DataSheet main 반영 완료**(`tables/Language.xlsx`)

개발 안내 문서 「오류 안내와 기능 중단 확인 안내」의 "기획자가 준비할 문구"에 맞춰 Language 탭에 행을 넣었습니다.

## 1. 한눈에 보기

| 무엇 | Language ID | 비고 |
| --- | --- | --- |
| 기능 중단 안내문 | **30330** | `{0}` 자리에 기능명이 들어감 |
| 기능명(선택 기능) | **30331~30336** | 이 기능만 멈추고 게임은 계속 |
| 기능명(필수 기능) | **30341~30347** | 실패하면 그 진행을 멈춤 |

- 새 행만 추가했습니다. 기존 행과 다른 탭은 바꾸지 않았습니다.
- 팝업은 새로 만들지 않았습니다. **Popup 15007**(복사·닫기)을 그대로 씁니다.
- 일반 오류 문구는 기존 ID를 그대로 씁니다(본문 30209, 복사 30210, 닫기 30211, 기록 파일 30212, 복사 안내 30214).
- 값에 소수·음수는 없습니다.

## 2. 안내문

| ID | 한국어 | 영어 |
| --- | --- | --- |
| 30330 | 오류가 발생하여 {0} 기능이 동작하지 않습니다. | An error occurred. The {0} feature is not working. |

`{0}`에는 아래 기능명 문구가 들어갑니다. 한국어·영어 모두 `{0}`이 한 번씩 있습니다.

화면에 보이는 예: "오류가 발생하여 배경음 재생 기능이 동작하지 않습니다." / "An error occurred. The Background Music feature is not working."

## 3. 기능명: 선택 기능

오류가 나도 이 기능만 멈추고 맵·전투 같은 다른 기능은 이어지는 것들입니다.

| ID | 한국어 | 영어 | 가리키는 것 |
| --- | --- | --- | --- |
| 30331 | 배경음 재생 | Background Music | 배경음·환경음 |
| 30332 | 효과음 재생 | Sound Effects | 효과음 |
| 30333 | 화면 연출 | Visual Effects | 판정과 관계없는 꾸밈 연출 |
| 30334 | 상태 표시 | Status Display | 체력·기력·재화 같은 화면 표시 갱신 |
| 30335 | 컷씬 재생 | Cutscene | 컷씬. 진행에 꼭 필요한 컷씬이면 필수로 다룸 |
| 30336 | 플레이 기록 전송 | Play Data Upload | 통계 전송 |

30337~30340은 선택 기능을 더 넣을 자리로 비워 뒀습니다.

## 4. 기능명: 필수 기능

실패하면 그 진행을 멈춰야 하는 것들입니다. 개발 문서 「필수 기능과 오류 처리 계약」의 필수 기능 목록을 플레이어가 읽을 수 있는 이름으로 옮겼습니다.

| ID | 한국어 | 영어 | 가리키는 것 |
| --- | --- | --- | --- |
| 30341 | 게임 데이터 불러오기 | Game Data Loading | 표·설정 데이터 준비 |
| 30342 | 맵 불러오기 | Map Loading | 맵·발판·캐릭터를 놓는 과정 |
| 30343 | 저장 | Save | 저장 |
| 30344 | 저장 기록 불러오기 | Save Data Loading | 이어하기, 새 게임 첫 기록 |
| 30345 | 맵 이동 | Map Transition | 맵·씬 이동 |
| 30346 | 전투 | Combat | 피해·사망·보상 처리 |
| 30347 | 조작 | Controls | 창을 닫은 뒤 조작·게임 시간 되돌리기 |

- 필수 기능 실패에도 30330 안내문을 쓸지, 기존 일반 오류 문구(30209)만 쓸지는 개발이 정해 주세요. 어느 쪽이든 쓸 수 있게 이름만 준비해 뒀습니다.
- 필수 기능 목록의 "기능 종료·정리"는 플레이어가 읽을 이름으로 옮기기 어려워 넣지 않았습니다. 필요하면 알려 주세요.

## 5. 부탁드릴 것

1. 기능마다 어떤 기능명 ID를 쓸지 연결해 주세요. 시트에 행만 있다고 자동으로 연결되지는 않는 것으로 알고 있습니다.
2. 여기 없는 기능에 안내가 필요하면 기능 이름만 알려 주세요. 기획이 Language에 행을 추가합니다. 화면 문구를 다른 곳에 직접 적지 않습니다.
3. 번호를 비워 둔 곳: 30323~30329(30324는 도끼 스킬 이름 자리), 30337~30340(선택 기능 추가 자리).
