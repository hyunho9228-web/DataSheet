## 2. 전투

### 2.1 패링 — 기획 필요

**피드백:** 패링이 의미가 없다. 체감이 약하다.

**회의:** 메리트가 확실하거나 디메리트가 확실해야 한다. 평타 위주로 싸우는데 스태미나가 빡빡하므로, 패링으로 스태미나를 회복시키는 방향도 함께 논의했다.

| 보상 후보 | 기대 효과 | 확인할 점 |
| --- | --- | --- |
| 피흡(체력 회복) | 위험을 감수한 보상이 즉시 보임 | 회복 아이템·서낭당 역할과 겹치는지 |
| 즉시 해체 | 강한 보상과 연출 | 보스·강적에게도 적용할지, 처형과의 구분 |
| 스태미나 전부 회복 | 스태미나 부족 불만을 함께 해결 | 처형 시 회복과 중복되는지 |

기존 QA 검토 연결: 패링 가능 예고 색이 실제 IsParryable과 같은지(C06), 패링 창 경계(C05). 현재 일반몹의 잡기·돌진·높이 던지기·후퇴는 패링 불가다.

### 2.2 스태미나 — 확정 + 보류

**피드백:** 스태미나가 빨리 닳아서 공격을 하고 싶은데 못 한다.

- **확정:** 처형 시 스태미나 회복
- **기획 필요:** 패링 보상으로 회복할지(2.1)
- **보류:** 아이템을 통한 스태미나 메리트

### 2.3 구르기·공격 중 회피 — 확정

**피드백:** 공격 중 회피가 잘 안 된다. 현민 님이 회피 추가를 말했던 건 확인 결과 회피는 이미 들어가 있다.

**결정:**
1. 구르는 시간을 줄인다.
2. 대신 구르는 동안은 방향과 상관없이 무적이다(현재는 600ms 중 400ms만 무적).
3. 구르는 중에는 **방향키만 막는다.** 다른 키로는 구르기 도중 캔슬할 수 있다.
4. 공격 중 회피의 허용 범위는 참고 게임의 키맵·조작 방식을 따라 정한다.

**논의됨, 미결:** 공중 구르기 허용 여부. 구르는 중 방향이 꺾이는 현상. 구르기 무적과 보스 쇠사슬 판정이 겹칠 때 보스 판정이 우선인지 명시가 필요하다.

**회피·치명타 UI(확정):** 발생할 때마다 이미지와 텍스트를 함께 띄운다.

### 2.4 결박가르기 — 기획 필요

**피드백:** 프레임이 너무 빠르다. 스킬 쓰는 맛이 약하다. 이동하면서 때려야 하는가?

**회의:** 기획을 잡아서 구체화한다. 준비 동작, 타격 순간, 이동 여부, 연출을 함께 정한다.

### 2.5 체력바 — 확정

몬스터·체세 체력바는 시인성이 괜찮아 유지한다. 피드백에 있던 "체력바의 하얀색이 무엇인가"는 별도 설명이나 표기가 필요한지 UI 작업 때 확인한다.

## 3. 이동·카메라·낙사

### 3.1 낙사와 카메라 뷰 — 기획 필요

**피드백:** 플레이어 대부분이 비슷한 곳에서 낙사한다. 위아래 확인 키 문제가 아니라 기본 카메라 뷰 문제로 보인다.

**회의:**
- 카메라 뷰 때문에 일반 평지가 낭떠러지처럼 보인다.
- 아래 보기를 할 때 일반 평지는 예외 처리가 필요하다.
- 단차가 큰 구간이 정말 필요한지 검토한다.
- 초반 낙사 구간은 기획을 다시 잡는다.

기존 QA 검토 연결(§10.3): 낙하 전에 착지 지형이 보여야 한다. 카메라 허용 범위, 높이, 중간 발판, 낙하 유도 표현 중 하나를 고르되 전역 카메라 값부터 바꾸지 않는다. 구덩이 즉사 정책은 유지한다.

### 3.2 레벨 배치

| 항목 | 상태 | 내용 |
| --- | --- | --- |
| 시작하자마자 왼쪽 벽 | 확정 | 제거 |
| 점프 높이가 집보다 높음 | 확정 | 집을 키움 |
| 장부방 안 플레이어와 문 크기 차이 | 확정 | 집 스케일 수정 |

## 4. 맵·탐색 구조

### 4.1 갈림길 — 기획 필요

**피드백:** 갈림길방에서 뒤로 돌아가는 루트가 있다(버그) / 갈림길방에 들어가면 뒤로 못 돌아가나?

**회의:**
- 표지판이 필요하다.
- NPC 대화로 힌트와 뉘앙스를 주고, 길에 대한 설명을 넣는다.
- "갈림길로 못 돌아가게" 선택지를 정하는 방식이 제안됐다.

기존 QA 검토 연결(§10.2): 되돌아갈 수 없게 만든다면, 필수 능력 없이 갇히지 않는지와 저장·사망 후 복귀 상태가 맞는지 확인해야 한다.

### 4.2 장부방 — 확정

**피드백:** 위 방향키로 장부방에 들어가면 카메라가 위로 튄다.

**결정:** 위 방향키는 카메라 보기 전용으로만 쓴다. 입장은 상호작용 키로 한다.

장부방 내부 상호작용 연출과 NPC 관련 UX는 6장에서 다룬다.

### 4.3 지역 구조 — 기획 필요

맵 간 연결성이 약하다. **가마터 구간, 설산 구간, 불타는 구간을 갈림길로 연결**하는 구조로 간다.

### 4.4 배경·지형 아트

| 항목 | 상태 | 내용 |
| --- | --- | --- |
| 배경 레이어 애니메이션 분리 후 배치가 부족해 보임 | 기획 필요 | 정확한 오브젝트 구성이 필요 |
| 바닥이 모두 같음 / 맵이 단조로움 / 맵이 어두움 | 기획 필요 | 전경으로 연출적으로 구성 |
| 전경·중경·원경 | 기획 필요 | 레이어 역할 정리 |
| 옹기 가마터길 배경, 길게 늘어진 바닥 이미지 | 진행 중 | 수정 중 |
| 안개 | 확정(조건부) | 알맞은 에셋이 있으면 이미지 대신 적용 |

### 4.5 위험 지형 — 기획 필요

**피드백:** 용암이 잘 안 보여서 피해야 하는지 처음엔 모른다. 용암 피해 범위가 이미지와 다르다.

**회의:** 용암과 얼음 모두 시인성이 좋지 않다. 기획 수정과 아트 작업이 모두 필요하다. 함정(죽창) 추가도 검토한다.

기존 QA 검토 연결(§2, §7.2): 보이는 범위와 실제 판정 범위를 맞춘다. 지속 피해의 간격과 무적 적용 정책을 명시한다(C13).

## 5. 아트·리깅

### 5.1 리깅 통일 — 확정

스프라이트와 리깅을 섞어 쓰던 방식을 리깅으로 통일한다. 아래 항목은 리깅 작업 뒤 다시 확인한다.

| 항목 | 리깅 후 할 일 |
| --- | --- |
| 플레이어 클라이밍 모션 | 리깅으로 교체. 사다리 콜라이더도 수정 |
| 좌우로 흔들 때 걷기 모션 누락 | 리깅으로 수정 |
| 서낭당 저장 시 앉기 애니메이션 미출력 | 리깅 후 확인 |
| 지게귀 달리기 모션 | 추가 |
| 허수귀 땅 내려치기·사망 사운드 | 싱크 수정 |

### 5.2 적·보스 — 리깅 후

리깅을 잡은 뒤 다시 논의한다. 보스는 아트와 함께 기획·연출도 수정이 필요하다. 피드백에서 나온 아래 항목을 그때 함께 본다.

- 보스 평타 모션 중 살짝 공중에 뜸
- 보스 공격 중 사슬이 어울리지 않음
- 보스 공격 이미지가 잘림
- 보스 공격 범위 원이 애매함
- 쇄문아비 2페이즈 전환 때 눈가림용 VFX 필요
- 보스 등장 시네마틱 연출

## 9. 기존 QA 검토와의 연결

회의 결정 중 코드 쪽 검증이 함께 필요한 항목이다. 근거는 기존 QA 검토(2026-11-22 코드 기준)이며, 실제 플레이로 재현한 결과는 아니다.

| 회의 결정 | 코드에서 확인할 것 | QA 문서 |
| --- | --- | --- |
| 리깅 통일 | 일부 연결이 첫 번째 자식 SpriteRenderer를 Body로 고르고, 보스 피격 영역이 보이는 그림 높이를 참고함. 리깅 교체 뒤 피격 범위·발 높이·공격 원점·좌우 반전이 바뀌는지 비교. SampleAnimation·SpriteSkin 비용 측정 | §2.1, §11.2, §12.5, R01 |
| 구르기 전체 무적 + 캔슬 | 현재 600ms 중 400ms 무적. 무적으로 무시된 접촉이 같은 공격에서 다시 맞을 수 있는 규칙과 함께 정리. 공격 → 구르기 허용표(현재 1~3타는 타격 종료 후, 4타는 불가) 갱신 | §3.3, §4, C04, M05 |
| 보스 쇠사슬 판정 우선 | 구속·사슬 판정과 구르기 무적의 우선순위를 코드에 명시. 사슬 중 사망·취소 시 구속이 남지 않는지 | §7.2, §11.4, §11.6 |
| 처형 시 스태미나 회복 | 처형 가능 여부가 코어 Grounded를 사용함. 발판 끝 점프 유예(100ms) 중 처형 허용 범위 결정 필요 | §5.1, M02 |
| 패링 보상 | 패링 가능 예고 색과 실제 IsParryable 일치. 보상 적용 순서(중단 → 자세 피해 → 보상 → 연출) | §3.1, §3.3, C05, C06 |
| 위 방향키 = 카메라 전용 | 입력 분리 후 장부방·사다리 위끝에서 카메라와 상호작용이 겹치지 않는지 | §10.3, X10 |
| 키맵 변경 | 입력 잠금·선입력 정리 로직 유지. 키 변경 후 F 안내 등 표시가 실제 바인딩과 일치 | §5.2, X07, X10 |
| 사다리 콜라이더 수정 | 사다리는 턱과 같은 Hang 상태를 쓰지만 피해 보호는 다름. 콜라이더 수정 후 피격·넉백·입력 복구 | §6.3, M11 |
| 갈림길 되돌아가기 제한 | 일방향 진입 뒤 영구 갇힘·저장 불일치 방지 | §10.2, X03, X04 |
| 낙사·카메라 | 낙하 전 착지 지형 노출. 구덩이 즉사 정책 유지 | §7.3, §10.3 |
| 용암 판정 | 보이는 범위와 피해 범위 일치. 지속 피해 간격 | §2, §7.2, C13 |
| 광기·피 연출 | 화면 효과 실패가 피해·상태 처리를 막지 않도록 분리. 연출 추가 후 공격 예고 가독성 유지 | §11.4, §12.6 |

## 10. 담당·작업 순서·미결 사항

### 10.1 담당

| 담당 | 작업 |
| --- | --- |
| 건호 | 대화창 기획 초안, 발소리 볼륨 |
| 건호, 영민 | 클라이밍 사운드 타이밍 |
| 미정 | 나머지 항목 |

### 10.2 권장 작업 순서

1. **리깅 통일**: 다른 작업 상당수가 여기에 묶여 있다. 교체 직후 피격 범위·발 높이·공격 원점을 비교한다.
2. **키맵 확정**: 참고 게임을 정하고, 대사 넘기기·서낭당 바치기·위 방향키 역할을 함께 정한다.
3. **전투 조작감**: 구르기 개편, 처형 스태미나 회복, 패링 보상 기획, 결박가르기 구체화.
4. **레벨 수정**: 왼쪽 벽 제거, 집 스케일, 카메라 아래 보기 예외, 초반 낙사 구간, 위험 지형 시인성.
5. **맵 구조**: 갈림길 기획(표지판·NPC 힌트·되돌아가기 정책), 지역 연결, 전경 연출.
6. **리깅 후 재논의**: 적·보스 기획·연출, 모션·사운드 싱크 재확인.
7. **UI·연출**: 사망 연출, 대화창, 장부방 상호작용, 광기·피 연출.
8. **후방 작업**: 아이템 시스템, 튜토리얼.

### 10.3 미결 사항

- 패링 보상은 피흡 / 즉시 해체 / 스태미나 전부 회복 중 무엇으로 할지
- 공중 구르기를 허용할지
- 구르기 무적과 보스 쇠사슬 판정이 겹칠 때의 우선순위 명시
- 키맵 참고 게임을 무엇으로 할지
- 갈림길에서 되돌아가기를 막을지, 막는다면 어떤 선택지로 안내할지
- 단차가 큰 구간을 유지할지
- 서낭당 특수 NPC 도입 여부
- 혼의 추가 사용처
- 함정(죽창) 도입 여부
- UI 애니메이션 범위
