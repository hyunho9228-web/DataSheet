# 개발 요청: 몬스터가 생성될 때 뒤돌아 있음 (11/17)

## 증상
맵에 들어가면 잡몹이 전부 같은 방향(오른쪽)을 보고 서 있습니다. 플레이어는 대부분 맵 왼쪽에서 들어오므로 몬스터가 등을 돌린 채로 보입니다.

## 원인 (학원 PC GitFork\Human_Ghost- 11/17 오전 코드 기준)
- `Core/Characters/MonsterActor.cs` 54줄: `public int Facing { get; private set; } = 1;`
  생성할 때 보는 방향을 정하는 곳이 없어 모든 몬스터가 1(오른쪽)로 시작합니다.
- `Decide()`는 어그로가 없으면 대기만 하고 `Facing`을 바꾸지 않습니다(372줄은 어그로가 잡힌 뒤에만 실행). 그래서 플레이어를 알아채기 전까지 계속 오른쪽을 봅니다.
- 그림은 `Preview/PreviewMonsterDriver.cs` 162줄 `_sprite.flipX = _monster.Facing > 0;`(지게귀는 `JigegwiRunView.cs` 59줄 스케일 반전)로 `Facing`을 그대로 따라가므로, 그림 쪽 문제는 아닙니다.
- DataSheet(spawn/*.json, Monster·Stage 표)에는 보는 방향 값이 없습니다. 프리팹 Scale 1.25(11/13)도 양수라 상관없습니다.

## 어그로에 주는 영향
11/16부터 인식이 보는 방향 기준 8방향입니다(`MonsterAwareness.WithinDirectionalRange`). 지금은 왼쪽에서 오는 플레이어가 전부 **후면**으로 계산되어 정면 6칸(600)이 아니라 후면 4칸(400)에서야 알아챕니다. 방향을 고치면 의도한 정면 인식 거리가 적용됩니다.

## 요청
1. 몬스터가 생성될 때 **플레이어 쪽을 보도록** 처음 `Facing`을 정해 주세요(생성 순간 플레이어와 몬스터의 x 위치를 비교해 한 번만, 같은 x면 왼쪽).
   - 맵에 들어오는 쪽(왼쪽 입구·오른쪽 입구)에 상관없이 맞습니다.
2. 어그로가 풀려 스폰 자리로 돌아간 뒤에도 마지막에 걸어온 방향 그대로 서 있게 됩니다. 돌아와 멈출 때도 같은 규칙(플레이어 쪽)으로 다시 돌려 주시면 좋습니다(선택).
3. 보스는 이번 요청 대상이 아닙니다.

## 확인 방법
도화골·산길·협곡·가마터에 왼쪽 입구로 들어가 잡몹이 모두 왼쪽(플레이어 쪽)을 보고 있는지, 정면 6칸 거리에서 알아채는지 확인.

## 참고
나중에 특정 몬스터만 일부러 등을 돌리게(기습용) 하고 싶으면 DataSheet 스폰에 방향 칸을 따로 추가하는 방식으로 다시 요청하겠습니다. 이번에는 데이터 변경 없이 코드 기본값만 바꾸는 요청입니다.
