# 필드 오브젝트(잔불·얼음 발판) 개발 전달 (11/13)

작성: 기획 김현호 · 상태: **DataSheet main 반영 완료**(`tables/FieldObject.xlsx`)

## 1. 한눈에 보기

몬스터를 줄인 맵에 이동·판단 거리를 주려고 **필드 오브젝트**를 넣습니다. 이번에 쓰는 것은 두 가지입니다.

| 종류 | 맵 | 플레이어가 겪는 것 |
| --- | --- | --- |
| **잔불** (불 장판) | 산길 2곳 | 장판 위에 있는 동안 피해를 받음(도트 피해). 위 발판으로 돌거나 구르기로 건넘 |
| **얼음 발판** (살얼음) | 협곡 3구간 | 얼음 위에서 넉백을 받으면 2배 멀리 밀림. 이동은 보통 땅과 같음 |

| 무엇 | 어디에 | 형식 |
| --- | --- | --- |
| 종류별 수치 | `tables/FieldObject.xlsx` **FieldObject** 탭 (21001~) | CSV 탭 |
| 놓는 자리 | `tables/FieldObject.xlsx` **FieldObjectPlacement** 탭 (22001~) | CSV 탭 |

- 두 탭 모두 새 탭입니다. 기존 탭의 열은 바꾸지 않았습니다.
- 스폰 JSON(`spawn/*.json`)은 바꾸지 않았습니다. 지금 배포 검사가 Placements 안 Objects에 NPC만 받기 때문에 자리를 표에 뒀습니다. JSON으로 옮기는 편이 좋으면 알려 주세요.
- 값에 소수·음수는 없습니다.

## 2. 이번에 구현이 필요한 범위

**ContentEnabled가 Y인 종류만** 게임에 나옵니다. 지금 Y는 두 행입니다.

| ID | 이름 | Kind | 이번 빌드 |
| --- | --- | --- | --- |
| 21001 | 잔불 | FIRE_STATIC | **사용** |
| 21301 | 살얼음(얼음 발판) | ICE | **사용** |
| 21002 | 번지는 불 | FIRE_CYCLE | 보류(N) |
| 21003 | 따라오는 불 | FIRE_SPREAD | 보류(N) |
| 21004 | 가마 불길 | FIRE_CYCLE | 보류(N) |
| 21101 | 길불 | GUIDE_FIRE | 보류(N) |
| 21201 | 장승 쉼터 | REST | 보류(N) |

보류 행은 수치만 남겨 둔 것이라 지금은 구현하지 않아도 됩니다. N인 종류를 가리키는 자리(FieldObjectPlacement 행)는 만들지 않습니다.

## 3. 잔불 (21001)

**게임에서 보여야 하는 것**

| 상황 | 결과 |
| --- | --- |
| 플레이어가 장판에 닿는 순간 | HP 5 감소 (바로 한 번) |
| 장판 위에 계속 서 있음 | 그 뒤 1초마다 HP 5 감소 |
| 장판에서 나옴 | 피해가 바로 끝남. 몸에 남는 화상·지속 효과 없음 |
| 구르기 무적 중에 지나감 | 피해 없음 |
| 다시 들어옴 | 닿는 순간 피해부터 다시 시작 |
| 몬스터가 장판 위에 있음 | 몬스터도 같은 피해(넉백으로 밀어 넣을 수 있음). 불붙은 허수귀(3003)는 안 맞음 |
| 장판 상태 | 늘 켜져 있음. 꺼지거나 번지지 않음 |

**쓰는 열**

| 열 | 값 | 뜻 |
| --- | --- | --- |
| Damage | 5 | 한 번에 들어가는 피해 |
| TickMs | 1000 | 서 있을 때 피해 간격(ms) |
| MonsterHit | Y | 몬스터도 맞음 |

나머지 열(WarnMs·ActiveMs·OffMs·SpreadSpeed 등)은 잔불에서는 0이고 쓰지 않습니다.

**확인 부탁드리는 것**
- 장판 피해에 피격 경직·넉백은 없는 것으로 생각하고 있습니다(HP만 감소). 피격 반응이 필요하면 알려 주세요.
- 장판 피해로 HP가 0이 되면 보통 사망과 같게 처리합니다.

## 4. 얼음 발판 (21301)

**게임에서 보여야 하는 것**

| 상황 | 결과 |
| --- | --- |
| 얼음 위에서 플레이어가 넉백을 받음 | 밀리는 거리 2배 (지게귀 돌진 2칸 → 4칸) |
| 얼음 위에서 몬스터가 넉백을 받음 | 같은 2배 |
| 얼음 위에서 걷기·달리기·멈춤·방향 바꾸기 | 보통 땅과 같음 (미끄러짐 없음) |
| 공격·점프·구르기 | 보통 땅과 같음 |
| 얼음 밖에서 넉백을 받음 | 원래 거리 그대로 |
| 구덩이 옆 얼음 위에서 구덩이 쪽으로 넉백을 받음 | 4칸 밀려 구덩이로 떨어짐(낙사). **의도한 결과**라서 얼음을 구덩이 가장자리까지 붙여 놓았습니다 |

**쓰는 열**

| 열 | 값 | 뜻 |
| --- | --- | --- |
| KnockbackRate | 20000 | 얼음 위에서 받는 넉백 거리 배율(만분율, 20000 = 2배). 계산이 정수라 정수배로만 씀 |
| SlideDistance | 0 | 멈출 때 더 미끄러지는 거리(칸×100). 이번엔 안 씀 |
| TurnMs | 0 | 방향 바꾸는 데 걸리는 시간(ms). 이번엔 안 씀 |

**확인 부탁드리는 것**
- "얼음 위"의 기준은 넉백을 **받는 순간 서 있던 자리**로 생각하고 있습니다. 밀리는 도중 얼음을 벗어나도 거리는 그대로입니다.
- 넉백 기본 거리는 StatusEffect 19001(200 = 2칸) 값을 쓰고, 여기에 배율만 곱합니다.

## 5. 놓는 자리 (FieldObjectPlacement 탭)

| 열 | 뜻 |
| --- | --- |
| StageID | 맵 (Stage ID) |
| PlacementID | 그 맵 스폰 JSON에서 붙을 플랫폼 줄의 번호 (101 = 땅 Ground) |
| FieldObjectID | FieldObject 탭의 종류 ID |
| X, Y | 몬스터 Points와 같은 규칙: 그 플랫폼 기준 x×100, 높이×100(바닥선 0). **X = 왼쪽 끝** |
| Width | 오른쪽으로 덮는 길이(칸×100) |
| GuideFireID | 길불 묶음 번호. 길불이 보류라 **이번엔 쓰지 않음**(값이 있어도 연결 없는 것으로 봄) |

**이번에 게임에 만들어지는 자리 5곳**

| ID | 맵 | 종류 | X | Y | Width | 맵 기준 위치 |
| --- | --- | --- | --- | --- | --- | --- |
| 22001 | 산길(8002) | 잔불 | 2100 | 0 | 600 | x21~27, 첫 장판(근처에 몬스터 없음) |
| 22003 | 산길(8002) | 잔불 | 9700 | 200 | 600 | x97~103, 높이 2 |
| 22009 | 협곡(8003) | 얼음 발판 | 900 | 0 | 1000 | x9~19, 입구 평지 |
| 22010 | 협곡(8003) | 얼음 발판 | 6600 | 0 | 1000 | x66~76, 구덩이(x76~83) 왼쪽 가장자리까지 |
| 22011 | 협곡(8003) | 얼음 발판 | 8300 | 0 | 600 | x83~89, 구덩이 오른쪽 가장자리부터 |

- 자리는 LDtk 시안 기준입니다. Unity 맵 지형과 어긋나면(공중에 뜨거나 땅에 묻히면) 알려 주시면 값을 고치겠습니다.
- 나머지 행(22002·22004~22008)은 종류가 보류(N)라 만들지 않습니다.

## 7. 저장

저장 항목은 **늘지 않습니다.** 잔불과 얼음 발판은 맵에 들어올 때마다 같은 상태로 만들어집니다.
(보류 중인 길불을 쓰게 되면 "켠 길불 목록" 저장이 필요해서, 그때 따로 전달하겠습니다.)

## 8. 나중에 쓸 수 있는 것 (참고, 이번 구현 대상 아님)

| 종류 | 움직임 |
| --- | --- |
| 번지는 불 | 예고 0.8초 → 2.4초 켜짐 → 1.8초 꺼짐 반복 |
| 따라오는 불 | 범위에 들어오면 0.8초 뒤 들어온 쪽에서 1초에 3칸씩 번짐, 6초 뒤 꺼짐 |
| 가마 불길 | 켜짐 1.6초·꺼짐 1.6초 박자 (새 맵용) |
| 길불 | 결박 가르기로 매듭을 끊으면 켜지고, 이어진 장판이 꺼짐 |
| 장승 쉼터 | 상호작용으로 HP 25 한 번 회복 |
| 얼음 미끄러짐 | 멈출 때 더 미끄러짐, 방향 바꾸기 지연 |

잔불·얼음 발판을 만들 때 종류가 늘어날 수 있다는 점만 참고해 주세요.

## 9. 개발 확인 요청 정리

1. 새 탭 2개(FieldObject·FieldObjectPlacement) 로딩

4. 자리를 스폰 JSON으로 옮기고 싶은지
5. 3·4번의 "확인 부탁드리는 것" 답
