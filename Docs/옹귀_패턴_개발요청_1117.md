# 옹귀(3005) 패턴 추가 요청 (11/17)

요청: 김현호 · 작업: 개발(리깅) · 데이터: DataSheet Monster 3005 / UnitStat 1007

## 왜 바꾸나요
2차 유저테스트에서 "옹귀가 짐 던지는 지게귀와 다를 게 없고, 던지기만 해서 더 쉽다"는 평이 나왔습니다. 그래서 **붙기 어렵게(뒤로 깡총)**, **움직이게(높이 던지기)** 하는 패턴 2개를 더합니다. 둘 다 새 그림 없이 지금 항아리 그림을 리깅으로 움직여 만듭니다.

## 1. 뒤로 깡총
| 항목 | 값 |
|---|---|
| 조건 | 막손이 옹귀 앞 2칸 안, 같은 층 |
| 동작 | 뒤로 2칸 뛰어 물러남. 공중 0.4초, 높이 약 1칸 |
| 이어지는 행동 | 착지하자마자 보통 던지기(대기 시간 건너뜀) |
| 쿨타임 | 3초 |
| 못 뛰는 경우 | 뒤 2칸 안에 벽·낭떠러지·발판 끝이 있으면 뛰지 않고 그 자리에서 던짐 |
| 판정 | 공격 판정 없음. 번쩍임 없음. 뛰는 중에도 맞음(무적 없음) |
| 리깅 | 웅크림 0.15초 → 뜀 → 착지 때 납작하게 찌그러짐 0.1초 |

## 2. 높이 던지기
| 항목 | 값 |
|---|---|
| 조건 | 막손이 3칸 이상 떨어져 있을 때. 보통 던지기 2번에 1번꼴로 섞음 |
| 예비 동작 | 0.5초, **붉은 번쩍(패링 불가)** |
| 동작 | 돌을 하늘로 높이 던짐. 던진 순간 막손이 서 있던 자리를 기억 |
| 떨어지는 곳 | 기억한 자리의 바닥(땅·발판 윗면). 던진 순간부터 그림자 표시 |
| 떨어지는 시간 | 던지고 1.2초 뒤 |
| 판정 | 떨어지는 자리 가로 1칸. 피해 = 옹귀 ATK(지금 18) + 0 |
| 피하는 법 | 구르기나 걸어서 자리 비키기. 패링해도 막히지 않음 |
| 리깅 | 보통 던지기 동작을 위쪽 각도로 다시 씀. 돌 그림 그대로 |
| 필요하면 | 그림자 원 1장(기존 원형 이펙트가 있으면 그대로, 없으면 아트 요청) |

## 바뀌지 않는 것
- 보통 던지기: 포물선, 패링 가능(흰 번쩍), 성공하면 돌이 부서지고 옹귀 스턴 1초.
- 스탯·보상·어그로·스폰은 DataSheet 그대로.
- 거리·시간 값은 개발 설정 값으로 둡니다. 플레이해 보고 조정해도 됩니다.

## 확인할 것
- ☐ 막손이 2칸 안으로 붙으면 뒤로 뛰고 바로 던짐, 3초 안엔 다시 안 뜀
- ☐ 뒤가 막혀 있으면 안 뛰고 던짐
- ☐ 높이 던지기 예비 동작에 붉은 번쩍, 그림자가 1.2초 뒤 떨어질 자리에 보임
- ☐ 높이 던지기는 패링해도 맞고, 구르거나 비키면 안 맞음
