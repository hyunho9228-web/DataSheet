# 쇄문아비 2페이즈(분노) 묘사·패턴 — 개발 전달

작성 2026-11-13 · 기획 김현호 · 대상: 개발(나영민), 애니(김현민) · 기준: 전투 기획서 C09 R3, 레벨 기획서 L07 R4, DataSheet main

> 상태: **확정(2026-11-13 김현호).** 시간·피해 값은 플레이해 보고 조정할 수 있습니다.

## 1. 한눈에 보기

- 2페이즈 그림에는 지금 **Idle, Walk, Attack1, Attack2** 네 동작만 있습니다. 패턴 1~4는 이 네 동작으로 만들고, 패턴 5·6은 **리깅으로 새 동작 2개**를 만듭니다(11/13 김현호, 6장 목록).
- 패턴은 6개입니다. 있는 동작으로 4개(기둥 내려찍기, 세 번 내려찍기, 긴 팔 휩쓸기, 기어 돌진), 새 동작으로 2개(**광역 땅 찍기**, **발악 뛰어 덮치기**)입니다.
- 구현 순서는 패턴 1~4 먼저, 그다음 5, 마지막 6을 권합니다. 5·6이 늦어져도 1~4만으로 2페이즈가 돌아갑니다.
- 사슬 당기기는 2페이즈 동작이 없어서 2페이즈에서는 쓰지 않습니다(1페이즈 전용).
- DataSheet: BossState 4002(HP 50% 이하, 패턴 사이 대기 600ms)는 그대로 씁니다. 맞았을 때 플레이어에게 걸리는 효과는 **StatusEffect 19002~19004**(넉백)로 새로 넣었습니다. 다운·감속은 Enum 분류가 생긴 뒤 넣습니다(4장). 아래 시간·피해 값은 지금처럼 개발 쪽 보스 패턴 설정값에 넣습니다.
- 원칙은 C09 그대로입니다. 모든 패턴에 붉은 예고, 화면 전체 공격 없음, 탄막 없음. 발악 뛰어 덮치기만 "공중 패턴 없음"의 예외인데, 공중에서 공격하지 않고 표시된 자리에 떨어지기만 합니다.

## 2. 2페이즈 묘사

| 항목 | 내용 |
|---|---|
| 조건 | 남은 HP가 50% 이하(500 중 250 이하)가 되는 순간 |
| 겉모습 | 다리가 무너져 사라지고, 밧줄로 묶은 나무 기둥 두 팔로 땅을 짚고 몸을 일으킴. 크기는 그대로. 몸이 낮아지고 팔이 길어 보임(11/11 회의 방향) |
| 움직임 | 두 팔로 땅을 짚으며 기어서 이동(Walk). 걸을 때마다 방울 소리와 나무 끌리는 소리 |
| 감정 | 문을 지키던 자세에서, 문을 닫으려고 매달리는 모습으로 바뀜. 대사 "닫아야 한다!"(30296)로 끝남 |
| 색·이펙트 | 몸에서 붉은 기운이 옅게 계속 남(예고의 붉은색보다 어둡게, 예고와 헷갈리지 않게) |
| 빨라지는 것 | 패턴 사이 대기 1000ms → 600ms(BossState 4002, 이미 들어가 있음) |

### 전환 순서

| 순서 | 일어나는 일 |
|---|---|
| 1 | HP 50% 이하가 되면 하던 패턴을 멈춤. 이때부터 전환이 끝날 때까지 보스는 피해를 받지 않음 |
| 2 | 포효(PhaseChange 상태). 화면 흔들림 + 붉은 번쩍 |
| 3 | 대사 24003 재생(9줄, 대화 중 게임 정지, 한 번만) |
| 4 | 다리가 무너지고 2페이즈 그림으로 바뀜. 아트의 변신 그림(등장 연출 프롬프트 ②)이 나오면 그것을 쓰고, 없으면 붉은 번쩍 사이에 그림을 바로 바꿈 |
| 5 | 체세를 가득 채움. 플레이어는 밀어내지 않음 |
| 6 | 전환 뒤 첫 패턴은 **기어 돌진** 고정(새 패턴을 바로 보여 주려고) |

- 급소 노출·해체 중에 HP가 50% 아래로 내려가면, 해체가 끝난 뒤에 전환합니다.
- 다시 도전할 때는 대사를 건너뛰고 2~5만 나옵니다(대사는 한 번만).

## 4. 맞았을 때 플레이어 상태·위치 변화 (1·2페이즈 전부)

11/13 추가. 효과 값은 DataSheet StatusEffect에 있고, 어느 패턴이 어느 효과를 주는지는 아래 표대로 보스 패턴 설정에서 연결해 주세요(MonsterSkill 탭은 보스를 가리킬 수 없어서 쓰지 않았습니다).

### 쓰는 효과 (StatusEffect)

| ID | 이름 | 내용 |
|---|---|---|
| 19002 | 보스 넉백 약 | 1칸 밀림, 200ms |
| 19003 | 보스 넉백 강 | 2칸 밀림, 250ms |
| 19004 | 보스 넉백 대 | 3칸 밀림, 300ms |
| 아직 없음 | 보스 다운 | 넘어져 600ms 행동 불가(분류 Stun, 값 0, 600ms) |
| 아직 없음 | 보스 땅 울림 감속 | 1000ms 동안 이동 속도 절반(분류 Slow, 값 5000, 1000ms) |

다운과 감속은 아직 StatusEffect에 넣지 못했습니다. Enum 시트의 StatusEffectKind에 Knockback만 있어서 Stun·Slow 행을 넣으면 배포 검사가 막힙니다. 개발에서 Stun·Slow 분류를 추가해 주시면 위 값으로 19005·19006 행을 넣겠습니다. 아래 표의 19005·19006은 그때 들어갈 번호입니다.

### 공통 규칙

| 항목 | 내용 |
|---|---|
| 기본 | 보스 공격에 맞으면 피격 경직 300ms, 그 뒤 피격 무적 600ms(지금 값 그대로) |
| 다운 | 다운이 붙은 공격은 경직 300ms 대신 다운 600ms. 일어난 뒤 피격 무적 600ms는 똑같이 걸림 |

| 약초 | 약초를 먹다가 맞으면 먹기가 끊김(지금 규칙 그대로) |

## 6. 리깅으로 새로 만들 동작과, 그림이 없는 상태

### 새로 만들 동작 (2페이즈 리그, 새 그림 없이 뼈 움직임만)

| 순위 | 동작 | 쓰는 곳 | 길이(예고 / 판정 / 회복) | 자세 설명 |
|---|---|---|---|---|
| 1 | 양팔 내려찍기 | 패턴 5 | 900 / 150 / 1000ms | 두 팔을 머리 위로 함께 들기 → 함께 내려찍기 → 박힌 팔 뽑기 |
| 2 | 뛰어 덮치기 | 패턴 6 | 800 / 공중 900 / 150ms, 마지막 회복 1500ms | 팔 굽혀 웅크림 → 팔로 밀어 솟음 → 팔 벌리고 떨어짐 → 착지 때 팔이 땅에 박힘 |

### 그림이 없는 상태와 대신 쓸 것

월요일 전에 3·4번 동작이 안 나와도 되도록 대신 쓸 방법을 적었습니다.

## 7. 완료 기준

- HP 50% 이하에서 전환이 한 번만 일어나고, 전환 중에는 보스가 피해를 받지 않음
- 2페이즈에서 패턴 1~5가 모두 나오고, HP 25% 이하에서 발악 뛰어 덮치기가 나옴. 패턴마다 붉은 예고가 보임
- 광역 땅 찍기의 땅 울림을 점프로 넘을 수 있음
- 발악 뛰어 덮치기는 붉은 원 밖으로 나가면 직격을 안 맞고, 두 번째 착지 뒤 1500ms 동안 때릴 수 있음
- 발판 +2, +4 위에 서 있어도 기둥 내려찍기 직격이 닿음
- 긴 팔 휩쓸기와 기어 돌진은 발판 +2 위에서 안 맞음
- 기어 돌진이 벽에 부딪히면 보스 체세가 30 줄고 800ms 멈춤
- 세 번 내려찍기를 다 피하면 1200ms 동안 때릴 수 있음
- 처음 하는 사람 기준 보스전 전체 2~3분(C09)

## 8. 확정된 결정 (11/13 김현호)

1. 2페이즈에서는 사슬 당기기를 쓰지 않습니다(1페이즈 전용). 발판에 숨는 것은 기둥 내려찍기가 위까지 닿는 것으로 막습니다.
2. 문 돌진은 기어 돌진으로 바꿉니다. 규칙(벽 충돌 체세 30, 발판 위 안전)은 그대로이고 그림만 Walk를 빠르게 씁니다.
3. 광역 땅 찍기와 발악 뛰어 덮치기를 넣습니다. 동작은 리깅으로 새로 만듭니다.
4. 발악 뛰어 덮치기는 C09 "공중 패턴 없음" 원칙의 예외입니다. 공중에서는 공격하지 않습니다.
5. 발악 조건은 HP 25% 이하입니다.
6. 패턴별 플레이어 상태·위치 변화를 4장대로 정합니다(넉백 1·2·3칸, 다운 600ms, 감속 1000ms, 패링 가능 여부).
